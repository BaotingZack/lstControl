# 倾角仪防摇方案可行性评估

**结论：方案可行，无致命缺陷；当前现场问题来自控制架构与判稳门槛，非传感器不可用。**

## 1. 物理与控制律

| 项 | 评估 |
|----|------|
| Δv = +K(L)·θ 追载荷阻尼 | 能量法正确，git `3632f43` 已修正符号 |
| 倾角仪提供 θ | 100 Hz，单摆 T≈3.1–3.4 s（FFT），与模型量级一致 |
| 离线影子闭环 (lst_024/025) | K=0.5 后残余 **0.15° ≤ 0.3°** |
| IMU 融合 | **非必须**；倾角仪单方案足以验证闭环，IMU 为后续增强 |

## 2. Bag 实证 (/dataSet/lst_001–005)

- **自适应判稳窗 ~3.43 s** 必要；0.6 s 窗漏检明显。
- **1 s 去趋势 PP（静止段 median）≈ 0.15–0.25°** → **0.3° 作夹取门槛合理**。
- **3.43 s 窗去趋势 PP 常 > 0.3°（0.5–2.1°）** → 用同一 0.3° 卡 **XY 到位等待** 会几乎永远超时。
- SLAM Z 不可靠；绳长/周期应使用 **PLC 抓钩高度** 而非 Map Z。

## 3. 原架构缺陷（非“方案不可行”）

1. **锁轴后关闭防摇** → 停稳阶段摆幅最大时无阻尼。
2. **判稳单一 0.3° 门槛** → 与 bag 长窗统计矛盾，流程长时间“假死”。
3. **固定 bias** → 抓钩张合/高度变化后 DC 残留（见 `doc/倾角仪初值`）。
4. **判稳窗暖机** 用 `t_start` 而非样本跨度 → 无谓延长等待。

## 4. v2 架构（本次实现）

```
倾角仪 → 轴映射 + 张/合 bias → θ
         ↓
    ThetaDcTracker → θ_ac（防摇与判稳阻尼共用）
         ↓
PD 环：未锁轴 → PD + Δv(+K·θ_ac)
      已锁轴 → 软阻尼 Δv（锚点 + 位移预算，防 bias 漂移）
         ↓
判稳：分级门槛
      XY 等待 → 0.6° 或仅 SLAM（上限 4 s）
      夹取/释放 → 0.3°（上限 6 s，超时软失败）
```

## 5. 验收指标

| 场景 | 目标 |
|------|------|
| 运动末 1 s 去趋势 PP | < 0.5°（较改前 1.5° 明显下降） |
| 夹取前 | < 0.3° 或超时继续 |
| 全流程 | 无 >10 s 无阶段进展；夹取动作必执行 |

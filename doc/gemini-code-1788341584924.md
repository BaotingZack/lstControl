# 三轴起重设备融合 IMU / 倾角仪防摇控制技术方案调研报告

**应用场景**：三轴独立驱动（大车 X / 小车 Y / 抓钩 Z 滑轮悬挂）  
**基础算法**：现有 PD 速度与位置控制  
**报告版本**：V1.0  

---

## 一、 场景特性与问题背景

本调研面向的工业应用场景为典型的三轴独立驱动起重设备（大车 $X$ 轴平移、小车 $Y$ 轴平移、抓钩/卷扬 $Z$ 轴升降）。抓钩通过钢丝绳与滑轮组悬挂在小车下方，构成一个典型的**变绳长、非线性、强耦合的多摆动力学系统**。

在现有设备控制系统中，大车、小车和卷扬三轴均采用经典的 **PD（比例-微分）控制算法** 实现位置与速度闭环。然而，仅靠常规 PD 轴控无法抑制机械加减速以及外界干扰引起的抓钩摆动。若要在保留现有稳定 PD 控制架构的基础上，融合 **IMU（惯性测量单元）/ 倾角仪** 以及 **高度/绳长传感器** 实现高效止摇，必须克服以下核心工程挑战：

1. **变绳长时变特性**：抓钩升降过程中，系统的固有摆动频率 $\omega_n(t) = \sqrt{g / L(t)}$ 实时变化（其中 $L(t)$ 为绝对绳长），变绳长收缩过程会引发能量积累与“收绳加速摇晃”现象。
2. **加速度干扰与假倾角**：倾角仪与加速度计在机构平移加减速时，会受到平移加速度 $a_{\text{transit}}$ 的严重干扰，直接读取倾角会导致控制失真。
3. **系统稳定性与工程可维护性**：防摇模块必须解耦，且具备良好的容错退出机制，不能破坏原有 PD 轴控的稳定性。

## 二、 权威技术路线选型与对比

综合工业界（如西门子 Crane Control、港口无雷达岸桥系统）及学术界权威方案，针对现有 PD 控制基础的改造路线对比：

| 控制路线 | 算法原理 | 优缺点分析 | 工程推荐度与适宜性 |
| :--- | :--- | :--- | :--- |
| **路线 1：全状态反馈 (LQR / MPC)** | 重构现有控制结构，将 $[x, v, \theta, \dot{\theta}]$ 构建状态空间方程，利用 LQR 或 MPC 生成驱动指令。 | **优点**：理论控制效果最佳。<br>**缺点**：对现有 PD 架构改动极大，调试难度高，算力开销大。 | ★★★☆☆<br>适用于全新搭建的高端自动化码头起重机。 |
| **路线 2：基于摆角的单纯外环 PD 反馈** | 在原 PD 控制器外层叠加一个摆角反馈回路，将角度偏差直接转换为速度补正量 $\Delta v$。 | **优点**：结构简单。<br>**缺点**：属于“事后纠偏”，对起停引发的大角度摆动响应滞后，易产生系统自激。 | ★★☆☆☆<br>仅适合低速、小摆角辅助稳摆。 |
| **路线 3：自适应输入整形 + 外环 PD 复合控制** | **开环前馈**：基于绳长 $L(t)$ 的自适应输入整形（AIS）抵消 85%+ 的主动摆动；<br>**闭环反馈**：基于 EKF 的摆角外环 PD 补偿外部干扰。 | **优点**：无缝兼容现有轴控 PD；前馈消摇效率极高；传感器失效可平滑降级。<br>**缺点**：需准确获取绳长。 | **★★★★★ (权威首选)**<br>工程落地的最佳技术路线。 |

> **权威路线推荐：复合控制架构（自适应输入整形前馈 + 摆角外环 PD 反馈）**  
> 该方案是目前工业界兼顾**防摇效果、系统鲁棒性与低改造成本**的最优选择。原有的三轴驱动 PD 环路完全保持不变，防摇算法作为“前馈速度整形器”和“动态速度叠加量”介入。

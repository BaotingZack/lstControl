# 桥式起重机防摇技术算法方案总结

**应用场景**：钢铁厂钢卷抓取，三轴桥式起重机（大车 X / 小车 Y / 抓钩 Z，滑轮悬挂）
**基础条件**：现有 PD 位置→速度伺服控制 + 自适应判稳调度（`s_curve.py` S 曲线模块存在但未接入控制环）
**目标**：在保留现有 PD 控制底座的前提下，融合倾角仪信息（倾角仪单方案，不融合 IMU），实现闭环防摇，缩短判稳等待时间、提高定位精度与安全性
**文档定位**：从调研结论到算法实现的衔接文档，作为后续详细设计与编码的输入

---

## 0. 一句话结论

**不要替换 PD，而是把 PD 从"固定参数、有限状态反馈"升级为"融合状态、实时绳长调度的闭环防摇 PD"。**

技术路线固定为：

```
S曲线前馈(待接入) → 输入整形ZVD/EI(前馈) → 摆角闭环防摇(反馈) → 现有三轴PD → 驱动器
                    ▲                          ▲
                    │                          │
            实时绳长 L(t)                 摆角 θ
              (起升高度推导)              (倾角仪)
```

第一版工程基线：**摆角闭环防摇（速度模式 `Δv=+K(L)·θ`）+ 倾角仪摆角提取 + 绳长增益调度**。
S 曲线前馈与 ZVD/EI 输入整形需先接入控制环（当前控制环为纯 PD，无前馈参考，见 §5.3）。
进阶路线：（可选）EKF → LPV-LQR →（仅高性能需求时）MPC。

## 1. 现有条件盘点（代码库现状）

### 1.1 已具备的能力

| 能力 | 实现位置 | 说明 |
|------|----------|------|
| S 曲线模块（未接入） | `s_curve.py` | 7 段式 jerk-limited 剖面模块存在，但**未接入** `run_pd_control`（纯 PD，`v_ref` 恒 0） |
| 位置→速度 PD | `pd_controller.py` | `v_cmd = Kp·e - Kd·v_filtered`（D 项用速度反馈做阻尼，可选限幅积分 Ki） |
| 三轴统一控制循环 | `crane_model.py::run_pd_control` | 10Hz PLC / 100Hz 仿真，PositionSource/Actuator 策略注入 |
| 作业调度 + 判稳 | `operation_scheduler.py` | 8 阶段钢卷取放流程 + 自适应判稳 |
| 抓钩高度反馈 | `plc_interface.py::GetActualLiftHeight` | 绝对高度 Z（绳长来源） |
| PLC 接口 | `plc_interface.py` | Snap7；X/Y 速度伺服、Z 绝对位置伺服（vz 积分成高度设定值） |

### 1.2 关键缺口（本次防摇升级要补的四项能力）

| 缺口 | 现状 | 后果 |
|------|------|------|
| **无摆角 θ 反馈** | 倾角仪/IMU 已装抓钩，但未接入软件、无摆角状态 | 闭环防摇缺失，只能被动等待摆动自然衰减 |
| **无绳长 L 进入控制器** | 仅知道 Z 高度，未算摆长 | 变绳长下固有频率 `ωn=√(g/L)` 时变，固定增益失配 |
| **无输入整形** | 仅靠 PD 参数抑制速度指令突变（无 S 曲线前馈） | 主动激励未系统性抵消，起停仍激发摆动 |
| **无摆动力学模型** | `crane_model.py` 只有运动学 + 低频速度扰动 | 无法做状态估计 / 预测 / 增益调度 |

### 1.3 现有"防摇"手段的本质（均为开环/被动）

现有代码通过三条措施间接抑制摆动，但它们**都不是闭环防摇**：

1. PD 参数整定（降低 `kp_pos`、提高 `kd_pos` 与速度滤波 τ）—— 抑制速度指令突变，减少对摆动的再激发（`s_curve.py` 的 S 曲线模块未接入控制环，实际无 S 曲线前馈）；
2. 提高 `kd_pos` + 速度滤波 `velocity_filter_tau_plc=0.80` + 防反向保护 `reverse_guard_tol` —— 抑制**速度指令**在目标附近的抖动，减少对摆动的再激发；
3. 自适应判稳 `hook_settle_*` —— 用位置峰峰值 / 漂移速度**被动等待**摆动衰减到阈值以下才执行抓取/释放。

其中第 3 条是当前**效率瓶颈**：判稳等待上限 `stabilize_delay=1.0s`、`gripper_settle_max_wait=2.0s`，摆幅大时只能干等。闭环防摇的价值正是**主动加速摆动衰减**，把这段等待时间大幅压缩。

## 2. 需求与约束

### 2.1 需求

1. **抑制摆动**：大车/小车启停、抓钩升降、边升边移等工况下主动衰减抓钩摆动；
2. **压缩判稳等待**：把被动判稳等待从"秒级干等"降到"快速收敛"；
3. **保精度与安全**：防摇不得牺牲定位精度（XY 残余 ≤0.02m、Z ≤0.04m 现状不倒退）；
4. **变绳长自适应**：起升/下降过程中摆长 L 变化，控制器参数需自适应。

### 2.2 硬约束

| 约束 | 值 | 影响 |
|------|-----|------|
| PLC 控制周期 | 10 Hz（定位 10Hz，Snap7 轮询） | 摆振频率 < 0.5Hz，Nyquist 5Hz 足够；防摇反馈带宽受 10Hz 限制 |
| 计算位置 | 上位机 Python（非 PLC 内） | 融合/EKF 可在 100Hz 跑，控制指令 10Hz 下发 |
| 执行器模式 | X/Y 速度伺服、Z 绝对位置伺服 | 防摇只能叠加到**速度指令**，Z 轴不能简单复制水平轴 PD |
| 现场调参遗产 | `kp_pos/kd_pos/τ` 已现场调定 | 防摇必须以**外环叠加**方式介入，不破坏现有闭环稳定性 |

## 3. 技术选型结论

### 3.1 为什么不用 LQR/MPC 做第一版

| 方案 | 结论 |
|------|------|
| 全状态反馈 LQR / MPC | 理论最优，但需重构控制结构、建精确模型、算力与安全验证成本高，**不宜作为现有 PD 的第一升级目标** |
| 滑模 / 鲁棒 / 自适应 | 抗扰强但抖振/调试成本高，作为第二/三阶段增强模块 |
| 视觉闭环 | 直接观测载荷位置，但受遮挡/光照/反光/镜头污染影响，作为高级闭环或冗余，**不作第一版唯一传感器** |

### 3.2 推荐路线的依据

工业界主流产品（ABB ACS880 Crane Control、Siemens SIMOCRANE Sway Control V5.0、Konecranes Smart Features）的防摇思想高度一致：**"轨迹/输入整形（前馈）+ 主动摆动抑制（反馈）"**，且 ABB/Konecranes 明确区分"Sway Control 通过加减速限制摆动"与"Active Sway Control 抑制已存在的摆动"——这正是"输入整形 + 摆角闭环 PD"的复合架构。

### 3.3 选型结论（与本场景匹配度）

| 模块 | 选择 | 理由 |
|------|------|------|
| 摆角感知 | 倾角仪（roll/pitch），装抓钩 | 倾角仪直接给出抓钩倾角=摆角，成本低、耐用；无 IMU 依赖 |
| 融合算法 | 倾角仪单方案（θ = roll/pitch 直接映射） | 控制律只需 θ，无需多传感器融合；EKF/IMU 作为后续可选增强 |
| 前馈 | ZVD/EI 输入整形 | 抵消主动激励，参数随 T(L) 调度 |
| 反馈 | 摆角闭环防摇（速度模式 Δv=+K(L)·θ，增益随 L 调度） | 与现有 PD 架构兼容最好、改造成本最低、可平滑降级 |
| 进阶 | LPV-LQR → MPC | 第二/三阶段，性能提升明显但复杂度递增 |

## 5. 算法详细设计

### 5.1 感知与物理模型

#### 5.1.1 硬件安装现状（已确认）

- **倾角仪安装在抓钩上**（`/inclination/j1939_msg`，输出 roll/pitch），随抓钩一起摆动；
- 抓钩通过**钢缆**与**升降电机**相连：升降电机收/放钢缆，改变抓钩高度 Z 与有效绳长 L；
- 编码器：大车/小车编码器给 x, y, vx, vy；抓钩高度 `GetActualLiftHeight` 给 Z（进而 L）；
- 倾角仪 roll/pitch 直接作为摆角 θ（角度制，需 ×π/180 换算），控制指令 10Hz 下发。

> 关键结论：传感器装在抓钩（摆动体）上，测得的**抓钩自身相对竖直的倾角即摆角 θ**，无需从"设备本体姿态"换算到"载荷摆角"（那只有传感器装在固定结构上才需要）。这正是调研推荐的位置。

#### 5.1.2 物理模型：钢缆悬挂的刚体摆

抓钩 + 钢卷通过钢缆悬挂在升降电机（经卷筒/滑轮）下方，构成**钢缆悬挂的刚体摆**，不是理想点质量单摆。三点需明确：

1. **有效摆长 L_eff ≠ 几何钢缆长度**：抓钩是刚体（有转动惯量），钢卷质心位于抓钩下方，且钢缆在负载下有弹性伸长。故有效摆长 = 几何绳长 + 质心偏移 + 载荷伸长。用 V0 自由摆实验标定 T(L_eff)，不硬套 ωn=√(g/L)。
2. **刚体转动模态（潜在双摆）**：抓钩绕钢缆挂点存在自身转动（姿态角），与钢缆摆角 θ 不完全等同。若抓钩/钢卷与钢缆间有明显相对转动或柔性连接，会出现**双摆**（第二低频模态）。用 V0 自由摆 + 频谱分析判断是否存在第二显著模态，确认后再升级双摆模型。
3. **钢缆弹性高频模态**：钢缆拉伸/回弹引入高频纵向抖动（bounce），频率远高于摆频（<0.5Hz），作为高频噪声滤除即可，不影响防摇主频段。

控制所需的摆角 θ 取**抓钩倾角**：它是摆动最直接的可测量，小角度下与钢缆摆角近似相等，且正是反馈要压到零的量。

#### 5.1.3 为什么不能直接用加速度计算摆角

加速度计测得的是**比力**（重力 + 运动加速度的矢量和），不是纯重力。即便行车静止，摆动中的抓钩自身也带切向/向心加速度；加上大车/小车加减速经钢缆传给抓钩的水平加速度，都会叠加到重力方向，直接用 `atan2` 会得到**假角度**。倾角仪单方案直接采用倾角仪角度作为摆角 θ；该"假倾角"（行车加减速污染，量级 ≈ ẍ/g ≈ 1°）是估计精度问题，由后续 EKF/加速度补偿解决，不改变"θ 用于 Δv=+K·θ"的有效性。

> 第一版采用**倾角仪单方案**：直接用倾角仪 roll/pitch 作为摆角 θ，不做互补滤波、不融合 IMU。§5.1.4 互补滤波与 §5.1.5 EKF 是后续融合 IMU 陀螺时的**可选增强**，不在第一版范围内。

#### 5.1.4 互补滤波（可选，融合 IMU 陀螺时用）

陀螺负责高频动态，倾角仪负责低频绝对基准：

```
θ̂[k] = α·( θ̂[k-1] + ω_gyro[k]·dt ) + (1-α)·θ_inc[k]
```

- `ω_gyro`：陀螺角速度（积分得到角度，动态响应快、有零偏漂移）；
- `θ_inc`：倾角仪/加速度计静态倾角（长期稳定、动态受运动加速度污染）；
- `α`：滤波系数，取 0.95~0.98（时间常数 `τ = α·dt/(1-α)`，约对应 0.5~1s）。

优点：计算量极低、容易接入现有 PD；缺点：难以系统利用编码器与 L 变化。作为 V1 快速验证，正式复杂工况升级 EKF。

#### 5.1.5 EKF（可选，后续增强）

**状态向量**：

```
X = [ θx, θy, θ̇x, θ̇y, vx, vy, L, L̇, bgx, bgy ]ᵀ
```

（`bgx, bgy` 为陀螺零偏，在线估计以消除积分漂移）

**过程模型**（小角度、变绳长摆动力学，每轴独立近似）：

```
θ̈x + 2(L̇/L)·θ̇x + (g/L)·θx = -ẍ/L
θ̈y + 2(L̇/L)·θ̇y + (g/L)·θy = -ÿ/L
```

**观测**：

| 观测量 | 来源 | 噪声特性 |
|--------|------|----------|
| θx, θy | 倾角仪 | 低频准确、动态受加速度污染 |
| θ̇x, θ̇y | 陀螺 | 高频准确、有零偏漂移 |
| vx, vy | 编码器 | 位置/速度精确 |
| L, L̇ | 起升高度 | 分辨率受限、受绳伸长/回差影响 |

EKF 把不同频率/噪声特性的传感器统一到物理状态空间中，迭代更新摆角与摆速估计。资源有限时先做 2 轴独立 EKF，确认存在明显三维耦合再升级统一状态模型。

### 5.2 绳长模型（变绳长是本案核心难点）

固有频率与周期：

```
ωn = √(g/L)         T = 2π√(L/g)
```

起升过程中 L 时变 → 摆动频率时变，固定防摇参数必然失配；且**收绳（L 减小）会引发"收绳加速摇晃"**（`2(L̇/L)θ̇` 项体现）。

**有效绳长推导**（本系统，区分几何绳长与有效摆长）：

```
L_geo(t)  = H_sheave − Z(t)                 （几何钢缆长度）
L_eff(t)  = L_geo(t) + h_com + ΔL_stretch   （有效摆长，V0 标定）
```

- `H_sheave`：卷筒/滑轮出绳点固定高度（现场标定）；
- `Z(t)`：抓钩实测高度（`GetActualLiftHeight`，钢缆直连抓钩）；
- `h_com`：抓钩挂点到钢卷质心的固定偏移（含吊具，现场标定）；
- `ΔL_stretch`：载荷下钢缆弹性伸长（随载荷变化，V0 标定）。

> 控制、增益调度与输入整形中的 L 一律使用 **L_eff**；它与几何绳长的差值（质心偏移 + 钢缆伸长）通过 V0 自由摆实验标定得到，而非按几何长度硬套 ωn=√(g/L)。

工程注意（调研明确）：动滑轮倍率必须进入机械映射；多层卷筒需考虑有效半径变化；钢丝绳弹性、机械间隙与回差会造成理论 L 与真实 L 偏差。建议软件中 **CraneModel（输出 L, L̇）与 AntiSwayController（消费 L）分离**。

### 5.3 输入整形（前馈）

输入整形把原始速度指令卷积成若干具有幅值/时间延迟的子指令，使各子指令激发的振动互相抵消。**PD 抑制已产生的摆动，输入整形在指令进入系统前降低对摆动模态的激励**，两者互补。

**零阻尼（ζ≈0，起重机近似成立）下的标准形式**：

| 整形器 | 脉冲序列 | 说明 |
|--------|----------|------|
| ZV | `[1/2, 1/2]` @ `t=0, T/2` | 参数最简单，对频率误差敏感 |
| ZVD | `[1/4, 1/2, 1/4]` @ `t=0, T/2, T` | 增加一个脉冲，频率失配鲁棒性更强 |
| EI | 幅度微调的三脉冲 | 残余振动容许范围内进一步提鲁棒性 |

**含阻尼 ζ 的一般式**（`K = e^(-ζπ/√(1-ζ²))`，`ΔT = π/(ωn√(1-ζ²)) ≈ T/2`）：

```
ZV  : A = [1/(1+K), K/(1+K)]                        @ t = 0, ΔT
ZVD : A = [1/(1+2K+K²), 2K/(1+2K+K²), K²/(1+2K+K²)] @ t = 0, ΔT, 2ΔT
```

**关键**：整形参数必须随 `T(L)` **在线更新或分段调度**（固定整形器在变绳长 + 风扰下存在适应性不足，已有 2018 年自适应 command shaping 研究佐证）。

**叠加位置**：`操作指令 → S曲线(v_ref) → ZVD/EI整形 → v_shaped`。ZVD/EI 作为 S 曲线速度指令的后处理，不侵入现有 PD。

> ⚠️ 前提：输入整形需要一个**前馈速度参考 v_ref** 去整形。当前 `run_pd_control` 是纯 PD 反馈（`v_ref` 恒为 0），无 S 曲线前馈，故 ZVD/EI 暂无法生效——需先把 S 曲线前馈接入控制环（见 §6），`input_shaper.py` 已实现为独立组件待接线。

### 5.4 摆角闭环防摇（反馈，本次核心新增）

**符号约定与物理依据**（能量法）：摆动力学 `θ̈ + (g/L)θ = −ẍ/L`（θ 正 = 载荷朝 +x 偏移）。摆能 `E = ½L²θ̇² + ½gLθ²`，沿轨迹 `dE/dt = −L·θ̇·ẍ`。要阻尼（dE/dt<0），必须让 θ̇ 与行车加速度 ẍ **同号**（"追载荷"）。

**速度模式**（现有执行器就是速度伺服，本次实际采用）——阻尼项反馈**摆角 θ**、符号为正：

```
v_cmd_final = v_cmd_pd + Δv_antisway
Δv_antisway = +K_sway(L)·θ            （速度 ∝ 摆角 = 追载荷）
```

代入得 `ẍ = K_sway·θ̇` → `dE/dt = −L·K_sway·θ̇² < 0`，摆能单调衰减，摆幅收敛。

> ⚠️ 常见错误：写成 `Δv = −K·θ` 或 `−K·θ̇` 都会失效——`−K·θ` → `ẍ=−K·θ̇` → `dE/dt>0` **失稳**；`−K·θ̇` → `ẍ=−K·θ̈` 只改等效惯量、不阻尼。速度模式下阻尼变量是**摆角 θ**，不是角速度 θ̇。

**加速度模式**（仅当将来执行器改为加速度伺服时使用）——阻尼项反馈**角速度 θ̇**、符号为正：

```
a_x_cmd = a_x_ref + Kp(L)·θx + Kd(L)·θ̇x
a_y_cmd = a_y_ref + Kp(L)·θy + Kd(L)·θ̇y
```

其中 `Kd·θ̇` 提供阻尼（`ẍ=Kd·θ̇` → `dE/dt=−L·Kd·θ̇²<0`），`Kp·θ` 提供恢复/加刚（提高固有频率）。两种模式的阻尼变量与符号不同，**不可混用**。

**增益随绳长调度**（`ωn=√(g/L)`，控制对象随 L 变化）：短绳/长绳分档，档间**线性插值**。

| 绳长区间 | 建议增益 K_sway |
|----------|----------------|
| 短绳 L1 | `K1` |
| 中短 L2 | `K2` |
| 中等 L3 | `K3` |
| 中长 L4 | `K4` |
| 长绳 L5 | `K5` |

### 5.5 起升轴的特殊处理

- 起升电机主要改变 L 并参与轨迹协调，**不能把摆角简单直接反馈到起升轴**（Z 是绝对位置伺服，`vz→高度设定值`已含积分环节，再叠加摆角反馈易双重积分自激——现有代码 `ki_pos_z=0` 的教训同样适用）；
- 起升/下降动作本身会激发摆动，应在**水平轴**防摇中通过 L/L̇ 时变项补偿；
- 大车/小车与起升动作**协同调度**，避免复合运动加剧摆动（边升边移时 ZVD/EI 参数需随 L 实时更新）。

### 5.6 进阶（第二/三阶段）

- **LPV-LQR**：`u = −K(L)·x`，统一考虑位置/速度/摆角/摆速；把 L 作为调度变量，在多个 L 工作点离线求 `K(L)`，运行时线性插值。性能明显高于固定 PD/LQR，复杂度显著低于 MPC。
- **MPC**：统一处理 X/Y/Z、摆角、速度、加速度、jerk、执行器饱和与 L 变化，仅在明确高性能三轴协调需求时实施。

### 5.7 传感器现场标定方法（倾角仪）

传感器安装朝向、输出单位（度/弧度/原始计数）、零偏、绳长等随现场而异，且抓钩经钢缆 + 2:1 动滑轮悬挂，部署前必须现场标定，否则融合出的摆角 θ 会在幅值、符号甚至单位上出错，导致防摇失效或反向激励。本节给出每项标定的目的、方法与产出物，全部填入 `CraneConfig`。

#### 5.7.1 标定总览与产出物

| 标定项 | 目的 | 方法 | 产出配置参数 | 代码状态 |
|--------|------|------|--------------|----------|
| 零偏标定 | 消除倾角仪零点 | 静止采集取均值 | 倾角仪零点偏移（无 IMU，陀螺零偏暂不需要） | ✅ 倾角仪零点 |
| 单位/量程 | 度 vs 弧度 vs 原始计数 | 已知角度翻转法 | `anti_sway_angle_scale` / `anti_sway_rate_scale` | ✅ 已支持 |
| 轴映射 + 符号 | roll/pitch ↔ θx/θy | 单轴激励法 | `SwayAxisMapping`（`sway_estimator.py`） | ⚠️ 当前硬编码默认 |
| 绳长 L_eff | 摆长随 Z 变化 | 自由摆测周期 | `rope_length_sheave_height` / `rope_length_grab_offset` / `rope_length_cable_stretch` | ✅ 已支持 |
| 阻尼比 ζ | ZVD/EI 参数 | 自由摆衰减拟合 | `input_shaper.py` 的 `zeta` 参数 | ✅ 组件已支持 |

#### 5.7.2 零偏标定（静态）

- **陀螺零偏**：倾角仪单方案无 IMU，暂不需要。
- **倾角仪零点**：抓钩铅垂静止（铅垂线确认竖直），读 roll/pitch 均值作为零点偏移。
- **加速度计（可选）**：六位置法（±g 各轴翻转）标定零偏与刻度，去除重力方向的固定误差。

#### 5.7.3 单位/量程标定

- 判断传感器输出是度、弧度还是原始计数值。
- 方法：把抓钩（或传感器夹具）绕已知轴翻转到已知角度（0°、±90°，用水平仪/量角器确认），记录传感器读数，线性拟合 `slope = Δ已知角度 / Δ传感器读数`。
- 角度制 → `anti_sway_angle_scale = π/180`；原始计数则用 `量程/满量程计数` 反推换算系数。

#### 5.7.4 轴映射与符号标定

- 目标：确定哪条传感器轴对应 θx（大车摆动）与 θy（小车摆动），及各自符号。
- 方法（单轴激励）：只驱动大车沿 X 加速-急停激发 X 向摆动，观察抓钩上哪条倾角仪轴显著摆动 → 该轴对应 θx；只驱动小车沿 Y 同理 → 对应 θy。
- 符号：朝 +X 摆动时若对应轴读数与摆动方向相反，则翻转其符号。
- 产出：`SwayAxisMapping`（`angle_source`/`rate_source`/`angle_sign`/`rate_sign`）。当前默认 `pitch→θx、roll→θy`（航天惯例）；若现场朝向不同需改 `sway_estimator.py` 的默认映射（⚠️ 暂无配置入口）。

#### 5.7.5 绳长 L_eff 标定（自由摆测周期）

- 固定抓钩高度 Z，拨动抓钩做自由摆，记录倾角仪信号，用 FFT 或过零检测测摆动周期 T。
- 由 `T = 2π√(L_eff/g)` 反推 `L_eff = g·(T/2π)²`。
- 在多个 Z（短/中/长绳）重复，拟合 `L_eff = H_sheave − Z + h_com + ΔL_stretch` → 得 `H_sheave`（出绳点高度）、`h_com`（质心偏移）；空载/有载对比得 `ΔL_stretch`（钢缆伸长）。
- 产出：`rope_length_sheave_height` / `rope_length_grab_offset` / `rope_length_cable_stretch`。

#### 5.7.6 阻尼比 ζ 标定（自由摆衰减）

- 记录自由摆摆角包络衰减曲线，拟合 `exp(-ζωn·t)` 得到阻尼比 ζ。
- 用于 ZVD/EI 的 `zeta` 参数（`input_shaper.py`，当前默认 ζ=0）。

#### 5.7.7 安装与结构检查

- 传感器装在抓钩刚性部位，避免局部弹性振动（弹性振动会混入高频假摆角）。
- 检查安装面水平度、螺钉松动、线缆应力与出线方向是否影响姿态。

#### 5.7.8 标定流程顺序（依赖关系）

```
安装检查 → 零偏 → 单位/量程 → 轴映射 → 绳长 → 阻尼比 → 增益整定(K_sway 由小到大闭环)
```

本节即 §7 V0 阶段「传感器标定」的具体化，所有产出填入 `CraneConfig` 后进入闭环调试。

### 6.2 与现有判稳的衔接（效率提升点）

现有判稳用 `hook_settle_pos_tol/vel_tol`（位置峰峰值/漂移速度），是摆动幅度的**代理**指标。升级后可直接用摆角/摆速判稳：

```
|θ| < θ_settle_tol  且  |θ̇| < θ̇_settle_tol  持续 hook_settle_window
```

判稳判据更直接、收敛更快，配合闭环防摇主动衰减摆动，可显著压缩 `stabilize_delay / gripper_settle_max_wait` 的实际等待时间。

## 9. 关键工程风险与降级

| 风险 | 对策 |
|------|------|
| 坐标系不一致 | 抓钩上的倾角仪轴须与行车 X/Y 方向对齐并明确标定（吊具/设备/世界坐标） |
| 安装刚度不足 | 倾角仪避免装在有局部弹性振动的结构上 |
| 时间同步/延迟 | 延迟直接降低反馈阻尼，需测端到端延迟 |
| D 项滤波相位 | 不能只追求低噪声，否则相位滞后增大 |
| 机械倍率/绳伸长/钢缆弹性 | CraneModel 单独维护 L_eff 标定；钢缆载荷伸长随载荷变化需一并标定 |
| 刚体转动/双摆 | 抓钩绕钢缆挂点的姿态角与摆角 θ 不完全等同；用自由摆频谱确认第二显著模态后再引入双摆模型 |
| 传感器故障 | 异常时**平滑降级**回"现有纯 PD + 判稳"安全模式，不因防摇失效破坏作业 |

# 末端减速消摆

用户已在本轮确认实施。优先目标是停车残摆和“到位且稳定”的总时间，
不要求运输全程摆幅最小；每轴分别验收，位置精度及取放货禁动边界不放宽。
002 原始记录只读。工作区已有修正全部保留，未经现场复测不宣称现场保证。

## 选择

保留现有 PD 走行，进入按速度和摆周期计算的末端窗口后，平滑加入可信轴的
角度阻尼。全程反馈作为对照；仅改固定介入距离不能解决反号/延迟，因此不采用。
不自动翻现场符号，不提高增益，不为了验证传感器而主动晃车。

## 反馈可信度

每段自然 PD 运动提供支点位移；在控制坐标内积分变绳长受迫摆模型。
拟合倾角时把未知初摆、常量偏置和线性漂移作为独立项，检查受迫响应的
符号、相位、独立激励大小和留出样本预测误差。无激励的自由摆不能确认符号。
连续检查通过前该轴保持 PD；通过后仍检查预测一致性，失配撤回。
它是保守的模型一致性门控，不是传感器标定或抓具动力学辨识。

## 末端与停车

按轴进入末端窗口，窗口至少为配置的 0.40 m，也覆盖约一个摆周期的行程。
允许轴的附加通路平滑建立，保留位移预算、按轴增长撤回和缺测退回 PD。
调度明确提供运输安全高度，等高运输不再被“高度等于目标”误判成贴近货物。
未提供安全高度的单点实机入口仍沿用原有贴货限制；不扩大未知工况的横移许可。

位置到位与稳定完成分别记录。可信末端反馈参与的水平运行在有限等待内继续
收敛，完整摆周期的原始 PP、位置误差和速度同时合格后停止反馈；超时如实记录。
其余运行保持原 PD 完成语义。仿真完成后也发零速并保留机械惯性和自由摆，
不能把持续控制的结果标为停车残摆。

## 验证

同路径、初始状态、伺服与观测时长比较 PD、原始反馈、当前修正、末端策略。
测试理想信号、实测静态偏置、反向、延迟、未知自由摆、缺测和变高度。
主指标：每轴停车后一个/三个周期的 PP、稳定完成时间、最终位置误差。
辅指标：途中峰值、RMS、首次到位时间、附加速度、资格和退出原因。
所有新结果由新命令驱动物理模型产生，和 bag 固定输入检查分开导出。
